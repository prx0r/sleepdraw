# CHANNELED — channel style reference (v1, 2026-09-27)

Dictated cosmos: Hilma af Klint's spirit-directed diagrams + Ra-style
transmissions. The hand is moved by something else — which is literally true
of our draw engine. Sources need verification in the volume before building.

## World

A quiet room where diagrams arrive: botanical specimens beside geometric
grids, concentric rings, soft biomorphic forms floating in black.

## Visual grammar (named sources)

- **Hilma af Klint**: diagram + organism pairs (wagtail + divided square),
  spirals, concentric circles, seven-pointed stars, swans, rose + shell
  duality, asemic glyph rows (unreadable by design — NEVER real letters).
- **Transmission aesthetic**: ruled grids, calibration marks, paired opposites
  (sun/moon, above/below), numbered-by-geometry-not-digits (rings count, not numerals).
- Motifs: spiral, target rings, specimen+diagram diptychs, androgyne pair,
  seven-star, white rose, shell.
- Palette: white pencil on black + ONE rose accent (#c97b8a): spiral cores,
  rose hearts, ring highlights. (af Klint is colorful; we translate to
  white-line + one warm note.)

## Prompt template

```
{diagram subject}, precise geometric grids beside soft biomorphic forms,
concentric rings and one spiral, botanical specimen detail, white pencil
etching on deep black.
No text, no letters, no numbers, no words. Wide landscape, generous black margins.
```

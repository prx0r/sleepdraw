# BOOKS — the translation × film flywheel (v1, 2026-09-27)

Loop: public-domain source → Pāṭala translates/verifies → sleepdraw
illustrates (etched plates) → KDP illustrated ebook + sleep film →
film description funnels to book, book backmatter funnels to channel.

## Why illustrated

B&W interiors = cheapest KDP print tier. Our etchings (white-on-black source,
inverted to black-on-white for print) are plate illustrations that cost
nothing and justify premium pricing. No stock art, no licenses, house style.

- **Pāṭala** (`/root/patalacheckpoints`): ingestion → translation per

  Anti-theatre law applies: no book ships unverified.

## Rules

- Never reprint a copyrighted translation. PD source or fresh Pāṭala
  translation only.
- Every plate credited: "etched by sleepdraw from [source]".
- One book = one film = one channel lock. No orphans.

## Rights law (read twice)

- Translating a COPYRIGHTED work needs the rights holder's permission.
  **Corbin (d.1978) is NOT public domain** (France life+70 → ~2049) — you
  cannot translate his French and sell it. Period.
- What you CAN own: fresh translations FROM public-domain sources. Ibn
  Arabi (d.1240) Arabic, Rumi Persian originals, Attar, Suhrawardi Arabic —
  all PD. Translate from the source language (Pāṭala's whole job), and the
  English is yours outright, forever.
- Rule of thumb: translate DEAD mystics (700+ years), never their
  20th-century interpreters, without a license.

## Book pricing (KDP verified 2026, Amazon.com)

- Formula: print = $1.00 + $0.012/page (B&W, 110–828pp). Royalty 60%.
- 100pp: print $2.20 → $9.99 list = **$3.79/copy**; $14.99 = $6.79; $17.99 = $8.59.
- 200pp: print $3.40 → $14.99 = $5.59; $19.99 = $8.59.
- Ebooks: 70% on $2.99–9.99 → $2.09–6.99/copy, zero print cost.
- Play: illustrated esoteric paperback at **$14.99–19.99** ($6–9/copy),
  ebook $4.99–7.99. Short texts (Shiva Sutras ~100pp) = fastest books.

## Cheapest printing (verified 2026 — KDP wins POD, offset wins bulk)

- **KDP**: free setup, cheapest print ($2.20/100pp, $3.40/200pp B&W).
  $16.99/200pp → **$6.79/copy** Amazon. Default for everything.
- **IngramSpark**: same print ±, but 45,000 retailers/libraries.
  $16.99/200pp @55% discount → $3.40/copy. Bookstore/library reach only
  (setup now free, no revision fees since Feb 2026).
- **BookVault**: premium objects (sprayed edges, foil, endpapers) + D2C
  Shopify native. The beautiful-edition lane.
- **Lulu**: odd formats only. Skip for trade paperbacks.
- **Offset**: wins past ~500 copies ($1.50–3/copy) + $200–800 plates +
  warehouse. Retreat bulk / confirmed pre-orders only.
- Stack: KDP (volume) + IngramSpark (reach) + BookVault (beautiful) +
  offset (retreats at 500+). Same PDF feeds KDP + Ingram.
